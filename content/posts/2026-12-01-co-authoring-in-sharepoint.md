Emailing *Budget_v7_final_FINAL.xlsx* around, or waiting for a colleague to close a file, is not necessary in Microsoft 365. If the file lives in SharePoint, OneDrive or a Teams channel, several people can work in it **at the same time**. This is called co-authoring.

## How to co-author

1. Put the file in a SharePoint library or a Teams channel (the **Files** tab).
2. **Share a link** to it instead of attaching a copy.
3. Everyone opens it from that link, in the browser or the desktop app.

You'll see the other people's initials and where they're typing. Changes appear within seconds. You don't need to merge anything.

Every save becomes a **version**. If someone deletes a paragraph by mistake, open **Version history** and restore the earlier version.

## When co-authoring doesn't work

If people get "file is locked for editing" or "someone else is editing", check these four things.

**1. The library requires check out.** In the library, go to **Settings › Library settings › Versioning settings** and look for **Require documents to be checked out before they can be edited?** If it says *Yes*, only one person can edit at a time. Set it to *No* unless you really need strict one-at-a-time editing.

**2. Someone is editing a downloaded copy.** If a person downloaded the file and is editing it on their desktop, their changes never reach the shared version. Ask people to open files from SharePoint, or to use **OneDrive sync** for the library so the file on their computer stays connected.

**3. The file is in an old format.** Co-authoring works with modern formats such as `.docx`, `.xlsx` and `.pptx`. Old formats like `.doc` or `.xls` don't support it. Open the file and save it in the new format.

**4. Someone is on an old version of Office.** Very old desktop versions of Office don't co-author well. Microsoft 365 Apps, or editing in the browser, avoid the problem.

## A good habit for teams

Pin the file in the Teams channel or add it to the site's navigation. When there is one obvious place to open it, nobody creates their own copy, and co-authoring just works.
