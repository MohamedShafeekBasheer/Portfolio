If you create the same kind of page again and again, such as a monthly update, a project page or a news post, you probably rebuild the layout each time or copy an old page and delete its content. A **page template** does that for you.

## Create a template

1. Build a page the way you want every page of that kind to look: sections, columns, web parts, headings and placeholder text like *"Write the summary here"*.
2. At the top of the page, open the drop-down next to **Save as draft** (or **Republish**) and choose **Save as template**.
3. Give the template a clear name, such as *Monthly department update*, and save it.

The template is stored in a **Templates** folder in the site's **Site Pages** library.

## Use a template

1. Choose **+ New › Page** (or **News post**).
2. The template picker opens. Your saved templates appear next to the built-in ones.
3. Pick yours, and the new page starts with the same layout and sections.

Fill in the content and publish as usual. The template itself doesn't change.

## Update a template

Open the **Templates** folder in **Site Pages**, open the template, edit it and save it again. New pages use the updated version; pages already created from it don't change.

## Tips

- **Use placeholder text that tells people what to write.** *"Two sentences: what changed this month"* works better than *"Lorem ipsum"*.
- **Keep the number of templates small.** Three good templates are used; fifteen are ignored.
- **Templates belong to a site.** If several sites need the same template, create it in each site, or ask your admin about organisation-wide options.

The payoff goes beyond saved time: every page of the same kind looks the same, so readers know where to find things and the intranet feels looked after.
