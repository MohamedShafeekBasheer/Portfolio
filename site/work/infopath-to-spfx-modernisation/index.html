Retiring InfoPath: 30+ forms rebuilt in SPFx

InfoPath forms on SharePoint 2013/2016 — and the SharePoint Designer workflows behind them — being rebuilt as SPFx React forms and Power Automate flows before Microsoft's support deadline.

Client
Al Qahtani Beverages
Where
Saudi Arabia
Length
Ongoing
Result
30+ forms modernised so far

The situation

The company's day-to-day processes ran on InfoPath forms in SharePoint 2013 and 2016, with SharePoint Designer workflows handling approvals and notifications. Microsoft is ending support for both.

What I did

  • Rebuilding each InfoPath form as a responsive SPFx React form.
  • Moving every SharePoint Designer workflow to Power Automate, keeping the same approval chains and notification rules.
  • Shipping in small batches so departments switch over one at a time.

What changed

  • 30+ forms modernised to date.
  • Legacy workflows on those forms fully replaced by Power Automate.
  • Programme still running at a steady pace.

Tools

  • SPFx
  • React
  • TypeScript
  • Power Automate
  • SharePoint Online
