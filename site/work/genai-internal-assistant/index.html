An internal AI assistant on Azure OpenAI and SharePoint

A GenAI assistant that searches SharePoint content and handles routine requests for several departments, built with Azure OpenAI, Copilot APIs and an SPFx front end.

Client
Al Qahtani Beverages
Where
Saudi Arabia
Length
In progress
Result
Pilot live in 2 departments

The situation

Several departments were spending time answering the same questions and processing the same standard requests, and finding documents in SharePoint wasn't easy.

What I did

  • Designing the assistant around Azure OpenAI and Microsoft 365 Copilot APIs, with an SPFx interface inside SharePoint.
  • Running alongside it: a standalone Security Guard application and a Freshworks ITSM integration that creates tickets automatically.

What changed

  • R&D phase complete.
  • Proof of concept live for 2 departments.
  • Production rollout under way, with more departments planned.
