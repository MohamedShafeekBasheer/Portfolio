World-clock and weather web parts for a Dubai intranet

Custom SPFx web parts — a multi-timezone world clock and calendar, and a live regional weather panel — for a modern SharePoint intranet serving staff across several countries.

Client
Food industry company (confidential)
Where
Dubai, UAE
Length
5 months
Result
Multinational intranet launched

The situation

A large food company in Dubai wanted its modern SharePoint intranet to be useful to staff spread across several countries. They needed live, local information that SharePoint doesn't provide out of the box.

What I did

  • Built custom SPFx web parts in React and TypeScript.
  • A world clock and calendar web part covering every office time zone.
  • A live weather web part with region-specific data pulled from REST APIs.

What changed

  • Web parts delivered and live on the intranet.
  • Better intranet engagement from international staff across multiple offices.

Tools

  • SPFx
  • React
  • TypeScript
  • SharePoint Online
  • REST APIs
